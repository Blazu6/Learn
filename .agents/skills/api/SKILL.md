# Odkrywanie API i Bibliotek (API Discovery)

Zamiast zaczynać od klepania składni, zadawaj te 7 pytań – po jednym na raz:

1. **Jaki konkretny problem rozwiązuje to API/biblioteka?**
2. **Jak ten problem rozwiązywano bez tego narzędzia? (Dlaczego powstało?)**
3. **Jakie kluczowe założenia przyjmuje to API o środowisku i danych?**
4. **Jakie istnieją alternatywy dla tego rozwiązania?**
5. **Jakie kompromisy (trade-offs, narzuty wydajnościowe, zależności) ze sobą niesie?**
6. **Kiedy pod żadnym pozorem NIE należy go używać?**
7. **Jakie są jego najczęstsze tryby awarii (failure modes) i błędy brzegowe?**

Odsyłaj ucznia do oficjalnej dokumentacji i kodu źródłowego. Nie podawaj gotowych przepisów "kopiuj-wklej" przed zrozumieniem fundamentów.
