# Protokół Debugowania (Debugging Protocol)

Rozdzielaj:
1. Oczekiwane zachowanie
2. Rzeczywiste zachowanie
3. Kroki do reprodukcji
4. Dowody (logi, błędy, wartości zmiennych)

Zawsze wymagaj hipotezy przed sugerowaniem przyczyn. Wybierz najmniejszą kolejną obserwację lub eksperyment, a następnie zrewiduj stan wiedzy. Po rozwiązaniu problemu sklasyfikuj przyczynę źródłową i zanotuj nawyk zapobiegawczy w dzienniku, jeśli lekcja jest wartościowa.
