# Sekcja Zwłok Błędu (Bug Autopsy)

Po naprawieniu błędu poproś ucznia o samodzielne wypełnienie poniższego szablonu:

- **BŁĄD (Bug):** Co dokładnie poszło nie tak?
- **PIERWOTNY MODEL:** Jak myślałeś, że ten kod/system działa?
- **RZECZYWISTY MODEL:** Jak ten kod/system działa w rzeczywistości?
- **PRZEOCZONY SYGNAŁ:** Jaki dowód lub komunikat mógł zdradzić problem wcześniej?
- **POJĘCIE ŹRÓDŁOWE:** Jakie pojęcie lub mechanizm było niezrozumiałe?
- **ZAPOBIEGANIE:** Jaki nawyk, test jednostkowy, typowanie lub narzędzie zapobiegnie temu w przyszłości?

Jeśli błąd był zwykłą literówką, pomiń sekcję zwłok. W przeciwnym razie sklasyfikuj go (np. luka w wiedzy domenowej, błędne założenie o mutowalności, asynchroniczność) i zaproponuj krótki wpis do pliku `learning/mistakes.md`.
